# 天地历 0.2.0

此版本依据五张参考图更新原生页面及对应功能。

## 安装与升级

安装 [tiandili-0.2.0-release.apk](tiandili-0.2.0-release.apk)，支持 Android 8.0 / API 26 及以上，targetSdk 36。包含 arm64-v8a、armeabi-v7a、x86 和 x86_64 四种 ABI；使用原 0.1.0 的发布证书，versionCode 从 1 升为 2，可覆盖安装。

建议先从「我的 → 系统设置 → 数据管理」导出备份，再将 APK 传到手机打开安装。安装来源授权由 Android 系统提示。不要卸载旧版再升级，以保留本地数据。

## 本次更新

- 五页导航改为日历、黄历、天气、发现、我的；红色月份栏、大日期、农历节日节气和黄色事项标签。
- 增加独立黄历与日期工具，支持年月选择、左右切月、返回今天和日期联动。
- 八类本地记录、分类摘要与标题/正文/子事项搜索；全屏分类编辑、待办子事项与完成状态。
- 生日与纪念日支持农历年重复，闹钟支持重复间隔与启停；关闭或完成记录会取消对应提醒。
- 原生系统闹钟声音、前台响铃通知、锁屏入口与停止操作，最多持续五分钟。
- 系统文件图片最多九张，采样加载、查看和无法读取时重新选择。
- 天气增加风向、昼夜背景、今天明天、24 小时与 15 日交互趋势、可用空气预报、城市切换和来源署名分享。
- 分组设置、三种主色、本地昵称、隐私与使用说明、备份恢复和仓库更新检查。

## 数据兼容

Room 数据库从版本 3 显式迁移至 4，旧日程保留 ID、时间、重复规则和提醒配置。JSON 备份格式升级至 2，继续支持格式 1；合并保留本机设置，替换覆盖日程、城市和设置，执行前会显示预览。

照片备份只保存系统文件引用，不包含原图。换机需另行复制照片并重新选择。已有周起始日设置保留，新用户默认为周日。

## 预览与验证范围

`ui-previews` 提供六个页面及窄屏、大字体、深色和天气最后一日选中的原生 Compose 预览。预览使用固定样例记录和气象数据，由 Robolectric 原生 Canvas 渲染。

签名、16 KB 对齐、四 ABI、DEX 038、压缩后的运行组件和 JSON 适配器，以及测试、Lint、构建结果见 [VERIFICATION.md](VERIFICATION.md)。

当前环境未完成真机安装或模拟器端到端验证。手机厂商后台限制、实际响铃音量、全屏授权、重启恢复、照片文件授权及启动器小组件仍需设备检查。

更新检查读取仓库的 `releases/latest.json`，本次文件和 APK 同步到远端后才会生效。
