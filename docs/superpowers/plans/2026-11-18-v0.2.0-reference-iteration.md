# 天地历 0.2.0 Reference Iteration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task in the current session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 更新原生 Android 应用以匹配五张参考图的页面与本地功能，并交付兼容 Android 8+ 的签名新版 APK。

**Architecture:** 在既有 Schedule / Room / 提醒 / 备份结构上增加类型化记录，避免创建第二套相互不同步的提醒数据。原生 Compose 分离页面、编辑表单、图表及系统能力；所有持久化变更使用渐进迁移和现有事务机制。

**Tech Stack:** Kotlin / Compose / Room 2.8.5 / DataStore / lunar-java / Retrofit / Moshi KSP / Glance / WorkManager / Robolectric / Android SDK 36。

---

设计依据：[图片参考设计](../../iterations/2026-11-18-v0.2.0-reference-design.md)。用户已授权本次更新；当前会话内实施，验证检查点不需要另一次执行授权。未经新的提交请求不创建 Git 提交。临时日志和脚本放在 `/tmp`；长期源码测试保留在项目测试目录。

测试核心内容：

```kotlin
val todo = Schedule(title = "读书",
    timing = ScheduleTiming.AllDay(LocalDate.of(2026, 11, 18), LocalDate.of(2026, 11, 19)),
    kind = ScheduleKind.TODO,
    checklist = listOf(ChecklistItem("第一章")))
assertThat(todo.checklist.single().completed).isFalse()
assertThat(ScheduleValidator.validate(todo.copy(mediaUris = listOf("file:///private/a"))))
    .isNotEmpty()
```
