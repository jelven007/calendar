# 天地历 0.2.0 图片参考迭代

本次范围来自用户提供的五张截图及“参考图片及功能，更新迭代一版”的实施请求，延续已批准的原生 Android、本地数据、可安装 APK 和 Android 8+ 兼容要求。

## 视觉与交互

视觉主张：以朱红、白纸和深色文字建立传统日历的清晰层级；天气使用与昼夜相符的蓝色场景，记录页使用轻量彩色分类。

内容结构：月历是主工作区；黄历和天气提供选中日期的上下文；“我的”组织个人记录；“发现”提供日期与节日工具。

交互主张：月份切换、选中日期的信息变化、记录编辑展开采用短而一致的过渡。保留点击按钮作为滑动操作的替代，所有主要触控区域至少 48 dp。

| 参考图 | 实现 |
| --- | --- |
| 红色月历 | 红色月份栏、年月选择、今天与新增、周末颜色、节日节气、黄色事项标签；选中日期下方显示农历、周数、干支和天气 |
| 待办编辑 | 横向类别选择、标题、提醒、子待办回车添加与勾选、完成保存；编辑时保留原重复规则和子事项 |
| 天气长页 | 城市切换、温度与风向风级、湿度和 US AQI、今天/明天、24 小时温度曲线、15 日高低温与农历日期 |
| 我的长页 | 十个快捷入口；记事、日程、生日、纪念日、闹钟、待办六个摘要区；搜索、设置、编辑和新增 |
| 系统设置 | 分组入口：皮肤、插件与通知、日历、提醒、天气、账号与数据、隐私、帮助、检查更新和关于 |

默认皮肤采用参考图的朱红，另提供青绿、蓝色以及明暗主题。新用户默认周日起始；已保存的周起始日继续按用户设置使用。

## 本地记录

采用一套持久化记录和既有提醒通道。`Schedule` 增加类别、完成状态、启用状态、子事项、媒体 URI；类别为记事、日程、生日、纪念日、闹钟、待办、影集、图文。

- 记事：标题、正文、日期、可选提醒。
- 日程：保留现有时间、全天、时区、重复、提醒和编辑删除功能。
- 生日：姓名、公历或农历日期、每年重复、可选提醒和下一次生日倒数。
- 纪念日：名称、日期、公历或农历年重复、已过天数和下一次倒数。
- 闹钟：时间、名称、每日/星期/间隔天数重复、启用开关；到时播放系统闹钟声音，并提供停止界面和通知。
- 待办：标题、子事项、完成状态、可选提醒；勾选父事项同时完成子事项，子事项状态反映整体完成情况。
- 影集：标题和最多九张通过系统文件选择器选择的图片，支持浏览、编辑与删除记录。
- 图文：标题、正文和图片，支持浏览、编辑与删除。

记事、影集、图文及无提醒待办不自动占用月历；有日期意义的日程、生日、纪念日、已启用闹钟和设置了提醒的记录可显示事项标签。已完成、已关闭或已取消的发生实例不显示为待执行事项。

农历年重复采用农历月日重新换算，不以公历日期代替。非闰月年份按普通同月处理闰月生日；不存在的农历三十取当月最后一天。支持范围继续为 1901–2099 年。

“我的”使用本地昵称与实际记录；账号与数据提供本地昵称及备份恢复。帮助与下载入口指向项目公开仓库。第三方会员与微信远程通知不作为本地功能入口。

## 存储与提醒

Room 版本从 3 升至 4。对 `schedules` 增加 `kind`、`enabled`、`completed`、`checklist_json`、`media_uris_json`、`reminder_minutes_before`；对 `recurrence_rules` 增加 `lunar_month`、`lunar_day`。

迁移保留原记录、ID、城市、取消实例和设置恢复日志；从旧 outbox 回填提醒偏移。关闭闹钟和完成待办时保留其提醒配置，取消正在等待的提醒。认领与派发也检查记录状态，防止旧广播继续提醒。

继续使用 09:00 作为全天提醒时刻。生日、纪念日和闹钟的初次保存直接选择当前时间之后的发生实例；普通历史日程保留既有错过提醒策略。闹钟只补发五分钟内错过的响铃，普通日程保留原 24 小时窗口。

闹钟声音使用前台媒体播放服务，限定响铃时长，退出与停止均释放资源。全屏展示、通知、精确闹钟接口按 Android 版本判断权限；无全屏权限时仍可从通知停止。设备时区变化后闹钟按设备本地时间重新规划。

## 备份与图片

备份格式升至 2，继续读取格式 1；旧文件的新增字段使用兼容默认值。所有类别、子事项、启用/完成状态、农历重复、昵称和皮肤均进入 JSON 备份。保留原合并去重、取消 tombstone 和数据库/设置恢复日志。

JSON 备份保存媒体引用，不复制原图。界面说明图片需单独保存；跨设备引用不可读取时显示重新选择入口。只允许系统选择器提供的 `content://` 引用，限制数量与长度；缩略图按采样解码，读取失败显示文字状态。删除影集记录不删除用户原图。

## 天气与工具

Open-Meteo 天气请求扩展为 15 日，并增加风向字段；保留分段缓存、时间标注、错误重试和来源链接。小时图展示 24 小时并可选择时间点，日图显示各日真实高低温和农历标签。

空气质量继续明确使用 US AQI；如提供小时空气预报，则按日汇总可用范围内的预报值，超出范围使用缺失状态。参考截图的数值与用户记录不作为预置数据。

“发现”提供日期间隔计算、日期前后推算和节日节气列表，可跳转对应日历日期。设置更新检查读取仓库发布元数据；读取失败有反馈与下载页入口，不自动下载安装包。

## 验收与交付

1. 五个顶层页面均可操作，日历选择与黄历日期同步；通知、小组件既有跳转继续工作。
2. 八类记录可创建、编辑、读取和删除；待办勾选、闹钟开关、农历生日、间隔天数和图片选择均有持久化验证。
3. Schema 1/2/3 可升级到 4；格式 1 可导入，格式 2 可往返；完成和关闭状态不会产生新的提醒。
4. 网络请求真实使用 15 日参数，图形由真实缓存/预报数据绘制。
5. 默认和 1.3 倍字体、窄屏和深色主题可使用；生成实际 Compose 页面预览与小组件预览。
6. Android 8 / 15 JVM 启动、全量单元与 UI 测试、Lint、发布 APK 结构、签名、四 ABI、DEX 038 和 16 KB 对齐检查通过。
7. 交付 `0.2.0` / versionCode `2`，复用原发布证书，APK、校验和、预览及变更记录放在 `releases/0.2.0`。

当前主机 Android 模拟器的硬件加速不可用；已有软件加速尝试失败。继续用 Robolectric 和 APK 检查完成可执行验证，真机通知、音量、全屏权限和厂商启动器行为列为设备验证边界。
