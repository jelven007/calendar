# 天地历

原生 Android 日历、黄历与本地记录应用。当前版本 **0.2.0**，支持 Android 8.0 及以上。

## 安装

安装包：[tiandili-0.2.0-release.apk](releases/0.2.0/tiandili-0.2.0-release.apk)。使用同一发布证书，可覆盖升级 0.1.0 并迁移原有日程。升级前可在「我的 → 系统设置 → 数据管理」导出 JSON 备份。

[更新与兼容性说明](releases/0.2.0/README.md) · [构建与验证](docs/RELEASE.md)

## 功能

- 日历：红色月份栏、农历、节日节气、事项标签、年月选择与滑动切月。
- 黄历：独立日期查看、宜忌、干支、彭祖百忌与方位。
- 天气：城市搜索与切换、实时天气、24 小时及 15 日趋势、可用空气预报与分享。
- 我的：记事、日程、生日、纪念日、闹钟、待办、影集与图文；本地搜索和分类摘要。
- 记录：农历年重复、轮班间隔、待办子事项与完成状态、闹钟启停、最多九张系统文件图片。
- 发现：日期间隔、前后推算、节日节气与日历跳转。
- 设置：三种主色、明暗主题、周起始日、本地昵称、提醒、桌面小组件、备份与恢复。

## 常见问题

**提醒未到达**：在「提醒设置」检查通知和精确闹钟权限，并在手机电池设置中允许后台运行。强制停止应用会影响提醒，请重新打开以恢复。日程提醒发送通知；闹钟使用系统闹钟音量，最多持续五分钟，可在通知或响铃页停止。Android 14 及以上的全屏闹钟还受系统授权限制。

**换机后图片无法打开**：JSON 备份包含系统图片引用，未打包原图。将照片另行复制到新手机后，在记录中重新选择。删除原文件也会使引用失效。

**更新检查失败**：可重试或打开仓库下载页。更新信息来自 `releases/latest.json`，需随新 APK 同步到仓库；当前本地构建不代表已发布到远端。

**隐私与数据**：无需账户，个人记录保存在本机。城市搜索、天气查询和更新检查需要联网。卸载或设备损坏可能丢失数据，请主动导出备份。

**天气或黄历**：天气数据来自 [Open-Meteo](https://open-meteo.com/)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，已进行中文化、单位转换与界面编排。空气预报仅显示可用日期。黄历资料用于传统文化参考。

## 开发

Kotlin、Jetpack Compose、Room、DataStore、WorkManager、Glance、Retrofit / Moshi 与 lunar-java。测试包括本地业务回归、原生页面渲染、闹钟与 Android API 启动检查。详细命令与验证范围见 [发布复核文档](docs/RELEASE.md)。
